# Module-system specification snapshot

A dated, read-only copy of the twelve `LOGOS-MODULE-*` draft specifications that
define the next Logos module architecture, taken **2026-09-18**.

It exists so that the wayfinding map's tickets can cite a section (`LOGOS-MODULE-RUNTIME
§5.2`) and have the next reader find the same words. Nothing here is authored in this
repo and nothing here should be edited: if the drafts move, replace the snapshot
wholesale and date it again.

The drafts are **heavily work in progress** and say so themselves — runtime, transport,
security and hash-suite selection are the rawest. Treat a conflict found against this
snapshot as a question to raise, not a defect to fix.
